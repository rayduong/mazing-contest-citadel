# 🏰 Mazing Contest // 2026 Citadel Arena Edition

A 3D multiplayer web recreation of the classic *Warcraft III: Reign of Chaos / The Frozen Throne* **Mazing Contest** custom map, built with **Three.js**, **Node.js**, **Express**, and **WebSockets (`ws`)**.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/rayduong/mazing-contest-citadel)

## ✨ One-Click Cloud Deployment
Click the **Deploy to Render** button above (or open `https://render.com/deploy?repo=https://github.com/rayduong/mazing-contest-citadel`) to deploy your own persistent 24/7 multiplayer server using [`render.yaml`](./render.yaml).

## 🎮 Features
- **Citadel Command Hub (Home Screen)**: Browse active public lobbies, join via room code, or launch an instant solo sandbox.
- **Host Match Configuration**: Customize Campaign Length (`3 / 5 / 8 Rounds`), Build Phase Timer (`45s / 60s / Default / 120s / ∞ Sandbox`), Castle Pillar Budget (`80% Ironman / 100% Standard / 125% Abundant`), AI Bot Count & Skill (`Novice / Architect / Grandmaster`), and Blind Maze Fog of War.
- **Grand Citadel Hall of Fame Leaderboard**: Persistent server-side leaderboard tracking Round Survival Records (`R1–R8`) and Career Champions.
- **All-Directional 2×2 Castle Pillars & Citadel Circuitry**: Link Red Keep Pillars into your Castle Pillar walls to Overcharge (`★` to `★★★`) Storm Spires, Frost Obelisks, and Chrono Spires.
